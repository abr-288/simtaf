# Sample Menewa

Exemples de démarrage pour vérifier le contrat entre les applications et l’API.

- `api.http` : requêtes HTTP pour l’endpoint de santé.
- `mobile-env.md` : configuration de l’URL API Flutter selon la cible.

Démarrez PostgreSQL et le backend selon [le guide](../docs/getting-started.md), puis utilisez les requêtes de `api.http`.
