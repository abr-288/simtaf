# Menewa SaaS

Application Next.js connectée au module Spring Modulith `projects`. Configurez `API_BASE_URL` (valeur locale par défaut : `http://localhost:8080/api`), démarrez PostgreSQL et le backend, puis lancez depuis la racine `pnpm dev --filter=@menewa/saas`. La page d’accueil liste les projets et permet d’en créer un.
